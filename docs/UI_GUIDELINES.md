# HelioVault — UI Guidelines

# Design Language

HelioVault uses a modern soft desktop UI aesthetic.

Core characteristics:

* rounded corners
* low visual noise
* subtle shadows/borders
* compact vertical density
* clean hierarchy
* muted secondary text
* purple accent system

---

# UI Principles

## DO

* keep spacing compact
* use subtle borders
* maintain visual consistency
* use rounded containers
* prefer clean layouts
* keep workflows obvious
* make actions discoverable

## DO NOT

* use classic Qt styling
* use hard-edged tables
* create spreadsheet-like pages
* overuse borders
* clutter the interface
* make scientific UI overly technical

---

# Color Philosophy

Primary accent:

* purple / indigo gradient system

Neutral colors:

* light gray backgrounds
* soft borders
* muted secondary text

---

# Typography

## Titles

* bold
* large
* strong hierarchy

## Secondary text

* muted gray
* smaller
* low emphasis

## Data rows

* compact
* readable
* medium emphasis

---

# Components

## Buttons

Characteristics:

* rounded
* compact
* hover feedback
* pointer cursor
* consistent sizing

---

## Dropdowns

Characteristics:

* rounded
* searchable
* compact
* mission-aware
* parameter-aware

---

## Result Rows

Rows should include:

* filename
* mission/instrument
* progress
* ETA
* actions

Rows should feel:

* lightweight
* dashboard-like
* modern

NOT:

* spreadsheet-heavy

---

# Scrollbars

Requirements:

* thin
* rounded
* subtle
* low visual weight

---

# Search Experience

Search should feel:

* fast
* guided
* visually clean

Loading states should:

* communicate activity
* avoid freezing UI
* remain minimal

---

# Downloads Experience

Inspired by:

* Chrome downloads
* browser download managers
* cloud dashboards

Should support:

* Pause
* Resume
* Cancel
* Open Folder

---

# Future UI Features

Planned:

* dark mode
* SVG icon system

* skeleton loaders
